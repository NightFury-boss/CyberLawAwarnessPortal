# Source Register — Cases Where Justice Fell Short

**Purpose:** Give Antigravity durable source locators and a verification checklist.  
**Priority:** Primary judgments, tribunal orders, parliamentary answers, government releases, regulator directions and official portals.

## Source-use rules

1. Retrieve the actual primary document, not only a search-result snippet.
2. Record the exact title, issuing authority, case/question number, date, URL, relevant page/paragraph and access date.
3. Preserve copies or stable links where licensing and project policy permit.
4. A web-search citation ID from the research conversation is a traceability hint, not a durable public URL. Re-resolve it to the actual document before publication.
5. If the primary document cannot be retrieved, mark the claim as unverified; do not promote a secondary report into a primary finding.
